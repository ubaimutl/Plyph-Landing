Built for how you actually work

Choose an action, review the result, and bring it back into your work.

Works where you type

Run actions on highlighted text in supported editors, browsers, notes, and email apps.

Bring your own AI

Connect a cloud provider or run a local model with Ollama. Use your existing ChatGPT account without an API key where account sign-in is available.

Unlimited custom actions

Create reusable prompts with variables like ${selection}, ${language}, ${tone}, and ${style}. Override provider and model per action.

Review before replacing

Preview and edit AI output before it replaces your original text. Or enable direct replacement for faster workflows.

Global shortcuts

Run common actions without touching the mouse. Keyboard-first design for power users who value speed.

Per-action models

Assign different providers, models, and token limits to different actions. Use a fast model for corrections, a powerful one for rewrites.

Privacy by design

When you run an action, Plyph sends the text you include and the action instructions to your chosen provider. With a model server on your device, the request goes there.

  • ✓ Provider credentials saved on your device
  • ✓ Direct connections to your chosen provider
  • ✓ No separate Plyph account required
  • ✓ Cloud requests follow your provider’s policies
  • ✓ Clipboard behavior depends on the platform
  • ✓ Local models supported via Ollama
